# Keyboard and mouse

[README](../README.md) · [Install](install.md) · [Keys](keys.md) · [Settings](settings.md) · [Building](building.md) · [Architecture](architecture.md)

Every shortcut can be changed in Options > Keyboard (Ctrl+,).

| Key | Action |
|---|---|
| ↑ ↓ PgUp PgDn Home End | Move (Shift = extend the selection) |
| Typing | Search: name, account, where it's used, any attribute value (every word must match) |
| Ctrl+F / Esc | Search field / clear the search, then leave it |
| Ctrl+P | Go to any item, in any keyring (fuzzy) |
| Ctrl+Shift+P | Commands |
| Ctrl+C | Copy the secret (cleared from the clipboard after 30 s, see [Settings](settings.md)) |
| Ctrl+Shift+C / Ctrl+Alt+C | Copy the account name / where it's used |
| Ctrl+R | Show / hide the secret in the details panel |
| Enter, double-click, Ctrl+E | Edit the item (on a locked item: unlock its keyring) |
| Ctrl+N | New item (in the keyring shown, else the default one) |
| Delete | Delete the selected items (asks first) |
| Ctrl+A | Select all |
| Space, Ctrl+I | Show / hide the details panel |
| Alt+↑ / Alt+↓, Ctrl+1..9 | Previous / next keyring, keyring n |
| Alt+Home | All items |
| Ctrl+Shift+N / F2 | New keyring / rename keyring |
| Ctrl+L | Lock all keyrings |
| F5 | Reload everything from the keyring service |
| Ctrl+= / Ctrl+- / Ctrl+0, Ctrl+wheel | Zoom |
| Ctrl+, / Ctrl+/ | Options / keyboard shortcuts |
| Ctrl+Q | Quit |

In the item editor: Tab / Shift+Tab move between fields, Ctrl+R shows the secret, Ctrl+G generates a password,
Enter saves, Esc cancels.

Mouse: click a column header to sort (again to reverse), drag its edges to resize, right-click it to pick columns.
Right-click an item or a keyring for its menu; middle-click an item copies its secret. Hover a keyring for its lock
button. Drag the sidebar's and the details panel's edges to resize them.
